# Made-up applicant

MADE UP. Not a real person.

Every name, address, phone number, email and parcel number in this folder is invented for testing
Pointer's in-browser redaction. Phones use the 555-0100 to 555-0199 range, emails use example.com,
the street ("Example Lane") and the parcel number (APN 999-999-99) are fictional. The permit
number, dollar amount and dates are placeholders, not real figures.

`applicant.ts` lists the sensitive values (must disappear after redaction) and the text that must
survive redaction untouched.
