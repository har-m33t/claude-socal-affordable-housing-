# Contributing

- **Notes vs. docs:** rough notes go in `research/notes/`; finished write-ups go in `docs/`.
- **Cite sources:** add every dataset or article to `research/sources.md` with the date accessed.
- **Data:** put original files in `data/raw/` and never edit them in place; save cleaned versions to `data/processed/`. Files over ~50 MB should not be committed: link to them in `sources.md` instead.
- **File names:** lowercase with hyphens, e.g. `la-county-rhna-progress.md`.
- **Commits:** short, descriptive messages (e.g. "Add Orange County income limits").
